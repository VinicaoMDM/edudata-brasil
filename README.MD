# EduData Brasil

Projeto de análise de dados públicos da educação brasileira.

## Objetivo

Construir uma plataforma analítica capaz de integrar dados públicos
de diferentes fontes para investigar relações entre investimento,
infraestrutura, características municipais e resultados educacionais.
Focando no estado de São Paulo.

## Status

Projeto em fase inicial de desenvolvimento.

## Tecnologias

- Python
- PostgreSQL
- SQL
- Git
- GitHub

## Fontes planejadas

- INEP
- FNDE
- IBGE
- SICONFI
- TCE
- MCP-Brasil

## Autor

Projeto desenvolvido para fins de estudo, portfólio e análise de dados públicos.
